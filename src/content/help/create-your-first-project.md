A project is the home of one production. Its budgets, planning, team, documents and costs all live here.

## Create a project

1. Open **Projects** in the sidebar (or **Budgeting**, which shows the projects in the budgeting phase).
2. Choose **New project** and fill in the details: name, client, project type and status.
3. Save. The project opens on its **Budgeting** tab.

You can also create a project directly from the projects overview with **Create New Budget**: this creates the project and its first budget in one go.

## The project toolbar

At the top of a project you find:

- **Budgeting**: build and manage budgets, set up budget lines, templates and price lists, and publish the approved budget to the production team.
- **Production**: track progress, manage crew and operations, and oversee scheduling.
- **Chat**: the conversation of this project.
- **Options**: duplicate the project, start a series, and other project actions.

Each tab has a sub-menu. The Budgeting sub-menu includes Overview, Project team, Briefing, Scripts, Format, Budgets, Compare, Images, Casting, Locations, Call Sheets, Documents, Links, Quotes and Scenes. The Production sub-menu includes Day Planning, Scenes, Locations, Casting, Scheduler, Planning, Cast & Crew, Recruitment, Stripbook, Editing, Delivery, Forecast, Project Finance, Cost Report, Committed costs (PO), Transactions, Invoices, Production dashboard and Production log. An administrator can adjust which items are shown under **Settings > Submenu**.

## Project team

Under **Project team** you decide who has access to this project and in which role. Approvals for costs on this project are routed to the people you assign here.

## Duplicate a project

**Duplicate** creates an independent copy of the project including all budget data. It is a good starting point for a similar production.

## Start a series

**Start a series** converts a standalone project into the first item of a series (for example Season 1, Episode 1). Give the series a name and type, and Tubes can create the next item automatically with **Create next project**.

> **Tip:** The first budget is usually the quickest way to give a project shape. See [How budgets work](/help/budgeting/how-budgets-work/).
