## Save a version

In the budget editor, give the version a name and choose **Save version**. Tubes stores a snapshot of every line as it is now. You can keep working; the snapshot does not change.

Saved versions are for your own history while building. Publishing a budget for the production team is a separate, formal step; see [Publish a budget and create a work budget](/help/budgeting/publish-a-budget-and-work-budget/).

## View or restore a version

1. Open the **Saved** panel on the left of the editor.
2. Choose a version to view it.
3. Choose **Restore** to make that version the current state of the budget. The version you were working on is not lost: save it first if you want to keep it.

## Lock lines

A locked line cannot be edited until it is unlocked again. Use it for lines that were agreed with the client or that come from a signed offer. Locking is per line; the rest of the budget stays editable.

## Versions and comparisons

Saved versions and published versions can be placed side by side in **Compare**. See [Compare budgets side by side](/help/budgeting/compare-budgets/).
