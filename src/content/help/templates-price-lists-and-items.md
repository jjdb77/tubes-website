Every budget you build from a template or with **Add items** draws on a small set of libraries. An administrator maintains them under **Settings**.

## Templates

A template is a standard production structure: phases, with activities in each phase, with resources under each activity, with the items that resource needs. A commercial, a documentary series and a live show each have their own template. Templates can be reordered, cloned and set as the default for new budgets.

**Build from template** in the budget editor copies this structure into the budget. Afterwards the budget is independent: changing the template does not change budgets that were already built.

## Items

Items are the individual things you budget: a camera operator day, a studio day, a drone permit, catering per head. Each item has a cost type, a unit and a default price. **Add items** in the editor picks from this library.

## Price lists

A price list holds prices for items, for example your standard rates, a client-specific rate card or last year's rates. A budget can use a price list so that the same item is priced consistently across productions.

## Building blocks

Building blocks are ready-made groups of lines (a lighting package, a standard edit) that you drop into a budget in one go.

## Cost categories and cost types

Every item and every budget line carries a cost type, and cost types are grouped in cost categories. That same chart is used for invoices and for the forecast, which is what makes budget, costs and reports line up. See [Cost categories and cost types](/help/settings/cost-categories-and-cost-types/).

> **Tip:** Colours per cost category make budgets and forecasts easier to read. You can import them in bulk from a CSV or Excel file with the cost category ID and a hex colour code.
